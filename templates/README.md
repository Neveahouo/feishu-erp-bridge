# 把你的 Excel 模板放在这里

模板文件本身**不入库**（`.gitignore` 已忽略 `*.xlsx`），原因：

1. 模板通常来自公司业务系统，可能有版权或保密要求；
2. 模板里往往带示例数据，公开发布容易泄露业务信息。

## 放置方法

1. 从业务系统导出/下载官方模板；
2. 重命名为 `template.xlsx` 放到本目录；
3. 在 `config.py` 里确认 `TEMPLATE_FILE = "templates/template.xlsx"`；
4. 按模板实际列顺序修改 `COLUMN_RULES`。

## 模板需要满足

- 第 1 行是表头；
- 数据从第 2 行开始；
- 多余的空白 Sheet 会被自动清理，不用手动删。
